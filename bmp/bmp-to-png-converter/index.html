About BMP and PNG Formats

BMP

BMP (Bitmap) is an uncompressed image format known for high-quality images and large file sizes, often used in Windows environments.

PNG

PNG (Portable Network Graphics) is a lossless image format ideal for web graphics with support for transparency and compact file sizes.
