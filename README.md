Convert Image is a free, static web application for converting common image and document formats in the browser. It is built with HTML, CSS, and vanilla JavaScript, with no application server or build step required.

The project includes dedicated conversion pages for PNG, JPG/JPEG, WebP, BMP, TIFF, ICO, and PDF files. Users can select or drag files into a converter, adjust the available options, process the files, and download the generated output.

## Features

- 42 dedicated conversion tools across seven source formats
- PNG, JPG/JPEG, WebP, BMP, TIFF, ICO, and PDF support
- Drag-and-drop and file-picker input
- Batch conversion on supported tools
- Quality, size, DPI, page-range, or transparency controls where relevant
- ZIP downloads for supported multi-file or multi-page conversions
- Responsive static interface with no account required
- Browser-side file reading, rendering, conversion, and download generation
- Informational format pages, FAQs, blog pages, and legal pages

## Supported conversions

| Source | Available outputs |
| --- | --- |
| PNG | JPG, WebP, BMP, TIFF, PDF, ICO |
| JPG/JPEG | PNG, WebP, BMP, TIFF, PDF, ICO |
| WebP | JPG, PNG, BMP, TIFF, PDF, ICO |
| BMP | JPG, PNG, WebP, TIFF, PDF, ICO |
| TIFF | JPG, PNG, WebP, BMP, PDF, ICO |
| ICO | JPG, PNG, WebP, BMP, TIFF, PDF |
| PDF | JPG, PNG, WebP, BMP, TIFF, ICO |

Support can vary by browser, image characteristics, available memory, and the third-party library used by a particular converter. Test important files before relying on the output.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas, `FileReader`, Blob, and object URL browser APIs
- PDF.js for reading and rendering PDF pages
- jsPDF for producing PDF files
- JSZip for downloadable batch archives
- TIFF.js / UTIF.js for TIFF processing
- ico.js and project conversion helpers for ICO processing
- Font Awesome for interface icons

Some libraries and visual assets are loaded from external CDNs. An internet connection is therefore required for all pages to work as currently configured, even though the file conversion itself is performed in the browser.

5. Open a terminal in the extracted project folder.

## Run locally

This project has no package installation or build command. Serve the repository over local HTTP because it uses root-relative paths and fetches reusable HTML fragments. Opening `index.html` directly with a `file://` URL may prevent some assets and components from loading.

### Python

Python 3 is preinstalled on many macOS and Linux systems:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

### Node.js alternative

If Node.js is installed, you can use a temporary static server:

```bash
npx serve .
```

Open the local address printed in the terminal.

## How to use a converter

1. Open the homepage and choose the required source and destination formats.
2. Open the dedicated converter page, such as `/png/png-to-webp-converter/`.
3. Drag compatible files into the upload area or use the file picker.
4. Adjust the quality, size, DPI, page, or transparency options when available.
5. Start the conversion.
6. Download the converted file or ZIP archive generated by the browser.

For the most reliable results, use the dedicated conversion page rather than treating a renamed file extension as a conversion.

## Privacy and security notes

The converter scripts read selected files through browser APIs and generate downloads using in-memory data and object URLs. The conversion code does not intentionally send selected files to an application server.

However, the current website also:

- loads some JavaScript libraries, icons, and images from third-party CDNs;
- includes Google Analytics on pages where the tracking snippet is present;
- uses browser `localStorage` for interface features such as ratings; and
- depends on the security and privacy behavior of the visitor's browser and loaded third-party resources.

Do not describe the project as completely offline or free of third-party requests unless those dependencies and analytics are removed or self-hosted. Avoid processing confidential files on a deployment you do not trust.

## Deployment

Because the project is static, it can be hosted with GitHub Pages, Cloudflare Pages, Netlify, Hostinger, Apache, Nginx, or another static hosting service.

When deploying a fork:

1. Upload the complete directory structure without changing asset paths.
2. Configure the host to serve `index.html` from the repository root.
3. Test root-relative assets and nested converter routes.
4. Update `convertimage.us` canonical URLs, structured data, `robots.txt`, and `sitemap.xml` if the public domain changes.
5. Review analytics IDs, verification tags, privacy text, and contact information before publishing.
